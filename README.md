# LegionLock

[Download LegionLock for Windows x64](https://github.com/BabyCRTTV/LegionLock/raw/refs/heads/main/LegionLock-Windows-x64.zip). Extract the ZIP and run LegionLock.exe.

Press LB + RB to cover all displays in black while Windows stays awake. Press a controller button or tap the screen to wake. Choose Change shortcut to save a different combination. The shortcut works while LegionLock is minimized.
